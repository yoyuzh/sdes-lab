# 用户指南

## 1. 启动程序

当前电脑可直接双击项目中的 `S-DES.app`；`启动.command` 可在终端启动并准备运行环境。本地 `.app` 使用项目根目录的 `.venv`，移动项目时请整体移动。

首次从源码运行，建议安装 uv 后，在项目根目录执行：

```sh
uv sync --frozen
uv run --frozen sdes-lab
```

如果没有 uv，可用兼容的 Python 手工创建环境：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/python -m sdes
```

手工 pip 安装根据项目依赖范围解析版本，不保证与 uv.lock 完全一致；需要复现验证环境时使用 uv。Windows 的虚拟环境入口为 `.venv\Scripts\python.exe`，程序在 Windows 尚未实际验收。

## 2. 二进制加解密

输入恰好 8 位数据和 10 位密钥，点击“加密”或“解密”。输入不接受内部空格，结果保留前导零。“复制结果”复制输出；下方显示子密钥、初始置换、两轮运算、交换和最终结果。

| 数据 | 密钥 | 操作 | 当前版本结果 |
|---|---|---|---|
| 11010111 | 1010000010 | 加密 | 11101000 |
| 11101000 | 1010000010 | 解密 | 11010111 |

如果另一组使用累计左移 3 位的 K2，同一加密示例会得到 `10101000`。不同实现比较结果时需核对转换表和位移规则。本组已与三点水小组完成组间测试，见[测试登记](../evidence/cross/README.md)。

## 3. ASCII 字符串

“加密 ASCII”接收 ASCII 文本，“解密 Hex”接收十六进制密文字节。每个字符独立按一个字节处理，空文本合法。非 ASCII 字符会提示字符位置，不进行有损替换。

示例：密钥 `1010000010` 加密 `Hello, S-DES!` 得到：

```text
E4 5C 89 89 AB DD C2 CB 56 9B 30 CB AD
```

将这串 Hex 放入输入框，点击“解密 Hex”，恢复 `Hello, S-DES!`。密文的字符预览将控制字符及高位字节转义为 `\xNN`，精确字节以 Hex 为准。解密输出含非 ASCII 字节时显示预览并提示核对密钥。

## 4. 暴力破解

每行输入一对二进制明文和密文，以空白分隔；通过添加或删除文本行增减输入对。例如：

```text
11010111 11101000
```

点击“开始破解”，程序枚举全部 1024 个密钥，显示候选、检查数、开始与结束时间以及耗时。该示例有 6 个候选，其中包含 `1010000010`。候选数为零时检查输入及算法约定；多个候选时可增加使用同一密钥的其他明密文对。

当前直接 LS2 规则下存在完全等价的密钥。例如 `1010000010` 和 `1110000010` 对全部分组具有相同加密结果；不能保证增加输入对就能得到唯一候选。

运行中的“取消”中止继续枚举，结果标记为未完成。任务很短时，点击取消之前可能已经完整结束，这是正常情况。

## 5. 碰撞分析

输入 8 位明文，点击“开始分析”，表格显示每个可达密文对应多少密钥；点击单元格查看该桶的密钥列表。

勾选“遍历全部 256 个明文”，程序覆盖 262144 个明文/密钥组合，显示每个明文的可达密文数、碰撞桶数、最大桶大小；点击单元格查看两个不同密钥产生相同密文的示例。

只有完整完成的结果才表示全空间结论；取消结果不能用于证明候选唯一或统计完备。

## 6. 保存结果

分析完成或取消后，“导出 JSON / CSV”可保存结果。默认目录为当前工作目录下的 `evidence/bruteforce` 或 `evidence/collision`；用户可选择其他路径。确认界面显示“已保存”并检查文件后，才视为保存成功。

JSON 含算法标识、环境、输入、结果状态和计时。CSV 为表格展示格式，二进制字段保持定长；表格软件可能自动去掉前导零，请按文本导入，或以 JSON 为精确数据依据。
